# AQYLDY KÜN — «Ақылды күн тәртібі»

«Ақылды күн тәртібі: математика және ЖИ арқылы оқушының уақытын тиімді пайдалану» зерттеу жобасына арналған ғылыми интерактивті зертхана («Зерде» конкурсы, 2-сынып). Интерфейс толығымен қазақ тілінде.

## Мүмкіндіктер

### Оқушыға арналған бөлімдер (2-сынып)

Әр бөлімде: «Артқа», «Басты бет», «Келесі» батырмалары, қысқа нұсқау, кезең көрсеткіші («1/3») және түсінікті нәтиже хабары. Бір экран — бір негізгі әрекет.

| Бөлім | Маршрут | Не істейді |
|---|---|---|
| Басты бет | `/` | 24 сағаттық интерактивті тәулік сағаты (1440 минут), 4 үлкен батырма |
| Менің күнім | `/my-day` | Иллюстрацияланған карточкалар, ± батырмалары, сағат→минут, Σ, бос уақыт = 1440 − Σ, асып кетуге тыйым, шеңбер диаграммасы, түсіндірме сөйлем |
| Тәжірибе | `/experiments`, `/experiments/1..3` | 1) Уақыт қайда кетеді? 2) 30 минутты өзгертсем не болады? (минут ауысу анимациясы, 1440 сақталуы) 3) Қай жоспар тиімді? (теңгерімді салыстыру) — «Қайта жасау», «Нәтижені сақтау», «Келесі тәжірибе» |
| Ақылды көмекші | `/helper` | «Жоспарымды тексер»: қосынды, қабаттасу, уақытқа сыю, міндетті істерді сақтау, жақсартылған жоспар, өзгерістердің себебі, математикалық тексеру. Түрі ашық көрсетілген: алгоритм, генеративті ЖИ емес |
| Уақыт математикасы | `/math` | 3 деңгей × 5 есеп: сурет (сағат, кесте), сан пернетақтасы, тексеру, қадамдық түсіндірме, қатені түзету |
| Менің зерттеуім | `/research` | Үлкен күн карточкалары (5/7/10/14), «Үлгілік тәжірибе» / «Менің нақты зерттеуім», сақтау, өзгерту, өшіру |
| Нәтижем | `/results` | Басылатын бағандар, экран мен кітап өзгерісі, жоспар/нақты, «Зерттеу есебін жүктеу» (PDF) |
| Жобамды көрсетемін | `/show` | 6 кезеңді қорғау режимі, толық экран, ← → пернелері |

### Ересектерге арналған толық зертхана (`/teacher`)

Алдыңғы нұсқаның барлық функциясы сақталған: 1440 моделі, толық тәуліктік конструктор, 5 эксперимент, ЖИ-көмекші параметрлері, 15 есеп тізімі, күнделік кестесі (JSON импорт/экспорт), кезеңдерді салыстыратын талдау, әдістеме, 9 слайдты қорғау.

**Деректер туралы:** зерттеу жұмысындағы 5 күндік кесте мен 2.2/2.3 кестелері әрқашан «Мысал (үлгі дерек)» белгісімен көрсетіледі. Нақты деректер тек «Менің нақты зерттеуім» режимінде енгізілгеннен кейін талданады; дерек жоқ болса, қорытынды жасалмайды.

## Технологиялар

React 18 + TypeScript + Vite 7, Tailwind CSS 4, Motion, Recharts, Zod, IndexedDB (`idb`), jsPDF (DejaVu Sans ішкі жиыны — қазақ әріптері үшін), Vitest.

## Жергілікті іске қосу

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # unit-тесттер
npm run build      # production → dist/
npm run preview    # dist-ті тексеру
```

Node.js 18.18+ (ұсынылады: 20 немесе 22).

## GitHub + Vercel

1. Осы папканың ішіндегі файлдарды (src/, public/, api/, tests/, package.json, package-lock.json, index.html, vite.config.ts, vercel.json т.б.) жаңа репозиторийдің түбіріне жүктеңіз. `node_modules` және `dist` жүктелмейді.
2. Vercel → Add New → Project → репозиторийді таңдаңыз.
3. Framework Preset: **Vite**, Build Command: `npm run build`, Output Directory: `dist` (бұлар `vercel.json`-да да көрсетілген).
4. SPA маршруттары үшін `vercel.json` ішінде `/index.html`-ге rewrite бар.

### Міндетті емес: тілдік модель (LLM)

`api/explain.ts` — оқшауланған серверлік функция. Ол тек Vercel-де **Settings → Environment Variables** ішінде `ANTHROPIC_API_KEY` (және қаласаңыз `LLM_MODEL`) орнатылғанда жұмыс істейді. Кілт браузерге ешқашан жіберілмейді (`VITE_` префиксін қолданбаңыз). Серверге тек әрекет түрлері мен минуттар жіберіледі — атаулар, аты-жөн, түсініктемелер жіберілмейді. Кілт жоқ болса, барлық зертхана жергілікті алгоритммен толық жұмыс істейді.

## Құрылым

```
src/core/        математикалық ядро (уақыт, 1440 бюджет, аралықтар, статистика, жоспарлаушы, kid.ts — бала моделі, есептер, күнделік схемасы)
src/kid/         оқушы интерфейсі (бөлімдер, иллюстрациялар, сағаттар)
src/data/        зерттеу жұмысының мәтіндері мен үлгі деректері
src/pages/       беттер (зертханалар, талдау, әдістеме, қорғау)
src/experiments/ 5 эксперимент
src/components/  UI, диаграммалар, уақыт сызығы, тәулік шеңбері, көмекші жұмыс алаңы
src/lib/         талдау, PDF, LLM клиенті, түстер
src/store/       IndexedDB және қолданба күйі
api/explain.ts   міндетті емес серверлік LLM функциясы
tests/           Vitest тесттері
```

Тексеру нәтижелері: `docs/VERIFICATION.md`.
