# Тексеру нәтижелері (v2.0, 2026-10-25)

## Нақты орындалған тексерулер

| Тексеру | Нәтиже |
|---|---|
| `npm test` (Vitest) | 6 файл, 70 тест — барлығы өтті (бала моделі, минут ауысу, теңгерімді салыстыру, көмекші, 3×5 есеп, ескі ядро, API, IndexedDB) |
| `tsc -b` + `npm run build` | қатесіз |
| Chromium (Playwright): 18 маршрут × 2 өлшем (1440×900, 390×844) | консоль қатесі жоқ, телефонда көлденең айналдыру жоқ |
| Басты бет | 4 негізгі батырма; сағат ± батырмасымен айналады |
| Менің күнім | «Кітап оқуға 15 минут қостың. Бос уақыт 15 минутқа азайды.»; 3-қадамда «… = 1440 мин ✓» |
| 1-тәжірибе | нәтиже сөйлемі дұрыс; «Нәтижені сақтау» → «Сақталған нәтижелер: 1» |
| 2-тәжірибе | экраннан кітапқа 30 мин: 60→30, 30→60, 1440→1440, «1440 минут сақталды» |
| 3-тәжірибе | Ә жоспарында ұйқы азайып, үй тапсырмасы көбейгенде — «Әр жоспардың өз артықшылығы бар» (тиімді деп жарияланбады) |
| Ақылды көмекші | мысал жоспарда қабаттасу және бос уақыт туралы ұсыныс; жақсартылған жоспар барлық тексеруден өтті; қабылдағаннан кейін «Жоспарың дұрыс…» |
| Уақыт математикасы | 1400 → «Әзірге дұрыс емес», түзету, 1440 → «Дұрыс!» + қадамдық түсіндірме |
| Менің зерттеуім | нақты режимде 2 күн жазылып, қайта жүктегенде сақталды |
| Нәтижем | экран 80 → 60 «20 минутқа азайды»; «Өзім ↔ Көмекшімен» картасы; PDF жүктелді |
| Жобамды көрсетемін | → пернесімен 6/6 кезеңге жетті |

## Тексерілмеген
- Vercel-ге нақты жариялау, нақты LLM жауабы.
- Нақты планшет/телефон, проектор, экран оқу бағдарламалары (тек Chromium эмуляциясы).
- Баланың өзі қолданып көруі (түсініктілік) — оқушымен бірге тексеру ұсынылады.
- Artifact алдын ала қарауында файл жүктеу (PDF, JSON) жұмыс істемейді — бұл алдын ала қарау ортасының шектеуі.
